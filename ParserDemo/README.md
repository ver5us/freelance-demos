# ParserDemo — сбор каталога в CSV за минуты вместо дней ручного копипаста

Демо-парсер для портфолио. Собирает каталог книг с тренировочного сайта
books.toscrape.com (сайт создан специально для практики парсинга, данные открытые):
название, цена, наличие, рейтинг — и складывает в аккуратный CSV.

## Запуск

```powershell
python -m venv venv
venv\Scripts\activate
pip install aiohttp beautifulsoup4
python parser.py              # 2 страницы каталога
python parser.py --pages 5    # больше страниц
```

Результат: `books.csv` рядом со скриптом (открывается в Excel) и сводка в консоли.

## Как проверить за 1 минуту

Запустить `python parser.py` — в консоли видно прогресс по страницам и первые
10 строк результата; открыть `books.csv` в Excel — данные структурированы по колонкам.

## Как показывать клиенту

Формулировка для переписки: «500 позиций конкурентов вручную собираются день,
парсером — 2 минуты, без опечаток. Вот пример таблицы, которую он выдаёт».
Прикладывать `books.csv` и скриншот консоли; под задачу клиента парсер пишется
под его список сайтов и полей.

## Что дорабатывается под реального клиента

- Любые сайты и поля клиента (цены, контакты, отзывы, объявления)
- Чистка дублей, нормализация цен и телефонов
- Автообновление таблицы по расписанию
- Выгрузка в Google Sheets вместо CSV

## Законность

Собираются только открытые данные без обхода защит и без персональных данных.
Если правила целевого сайта запрещают автоматический сбор — задача отклоняется
или предлагается легальный источник (официальный API, выгрузка площадки).
