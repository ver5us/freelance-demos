# ParserDemo — сбор данных с сайтов в таблицу за минуты

Демо-проект для портфолио. Парсер собирает каталог книг с тренировочного
сайта books.toscrape.com (сайт создан специально для практики парсинга,
данные открытые): название, цена, наличие, рейтинг — и складывает всё
в аккуратный CSV. Ровно этот подход переносится на любые задачи клиента:
цены конкурентов, каталоги, контакты, отзывы, объявления.

## Для кого этот проект

- Селлеры маркетплейсов и магазины: мониторинг цен конкурентов
- Маркетологи и аналитики: сбор каталогов и контактов для баз
- Владельцы бизнеса, которым сейчас «это собирает менеджер руками три дня»

## Какие проблемы решает

- Ручной копипаст страниц заменяется запуском скрипта на пару минут
- Нет опечаток и пропущенных строк: данные структурированы по колонкам
- Повторный сбор — одна команда, результат перезаписывается аккуратно
- Данные сразу готовы к анализу: CSV открывается в Excel и Google Sheets

## Возможности

- Сбор нескольких страниц каталога за один запуск (`--pages N`)
- Извлечение полей: название, цена, наличие, рейтинг (звёзды → число)
- Прогресс по страницам и превью первых строк прямо в консоли
- Результат — `books.csv` в кодировке UTF-8 с BOM и разделителем «;»:
  русский Excel открывает файл по колонкам и без «кракозябр»
- Остановка на конце каталога или при недоступной странице без падения
- Вежливый сбор: только открытые данные, без обхода защит

## Стек

Python 3.10+ · aiohttp · BeautifulSoup4

## Установка и запуск

### Windows (PowerShell)

```powershell
# 1. Создать виртуальное окружение
python -m venv venv

# 2. Активировать его
venv\Scripts\activate

# 3. Установить зависимости
pip install aiohttp beautifulsoup4

# 4. Запустить парсер (2 страницы каталога)
python parser.py

# 4а. Или больше страниц
python parser.py --pages 5
```

### macOS / Linux (терминал)

```bash
python3 -m venv venv
source venv/bin/activate
pip install aiohttp beautifulsoup4
python parser.py
python parser.py --pages 5
```

Результат: файл `books.csv` рядом со скриптом + сводка в консоли.

## Тестовый сценарий (2 минуты)

1. Запустите `python parser.py` — в консоли виден прогресс: «Страница 1:
   собрано книг — 20», «Страница 2: собрано книг — 20».
2. Откройте `books.csv` в Excel: данные разложены по колонкам
   title / price / availability / rating, кириллица и символы цен читаемы.
3. Запустите `python parser.py --pages 5` — соберётся 100 книг, файл
   перезапишется целиком, дубли страниц не появятся.
4. Отключите интернет и запустите ещё раз — скрипт корректно остановится
   с сообщением о недоступной странице, а не упадёт с traceback.

## Как показать демо клиенту

1. Запустите парсер на демонстрации экрана: прогресс в консоли выглядит
   как «работа машины», это продаёт лучше любых слов.
2. Откройте полученный CSV в Excel рядом с сайтом-источником — видно,
   что каждая колонка соответствует данным страницы.
3. Формулировка для переписки: «500 позиций конкурентов вручную собираются
   день, парсером — 2 минуты, без опечаток. Вот пример таблицы. Под вашу
   задачу напишу такой же под ваши сайты и поля, с пробным фрагментом
   из 20 строк до оплаты».

## Что дорабатывается под реального клиента

- Любые сайты и поля клиента: цены, наличие, контакты, отзывы, объявления
- Чистка дублей, нормализация цен и телефонов, склейка источников
- Автообновление таблицы по расписанию (ежедневно/еженедельно)
- Выгрузка в Google Sheets вместо CSV, уведомления о завершении сбора
- Обход ограничений вежливо и легально: задержки между запросами,
  уважение к robots.txt, использование официальных API, если они есть

## Законность

Собираются только открытые данные без обхода защит и без персональных
данных. Если правила целевого сайта запрещают автоматический сбор —
задача отклоняется или предлагается легальный источник (официальный API,
выгрузка площадки).
