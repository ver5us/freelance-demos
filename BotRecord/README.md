# BotRecord — Telegram-бот записи для малого бизнеса

Демо-проект для портфолио. Бот онлайн-записи для салона красоты, клиники,
барбершопа, фитнеса или автосервиса: клиент выбирает услугу, дату и свободное
время, оставляет имя и телефон — владелец бизнеса мгновенно получает
уведомление в Telegram.

## Для кого этот бот

- Салоны красоты, барбершопы, косметологи, мастера маникюра
- Частные клиники, стоматологии, психологи
- Фитнес-тренеры, массажисты, репетиторы
- Автосервисы, детейлинг, шиномонтаж
- Любой малый бизнес, где клиентов записывают «в личке» или по телефону

## Какие проблемы решает

- Заявки больше не теряются в переписках и директе
- Клиент записывается сам, в любое время суток, без звонка
- Одно и то же время нельзя занять дважды под одну услугу — нет накладок
- Разные услуги могут идти в одно время (параллельные мастера/кабинеты)
- Владелец видит новую запись мгновенно
- Клиент может посмотреть и отменить любую свою запись, слот освобождается

## Возможности

- `/start` — главное меню: Записаться / Мои записи / Отменить запись / Помощь
- Выбор услуги из каталога (4 демо-услуги, заменяются за пару минут)
- Выбор даты на 7 дней вперёд в человекочитаемом формате («Пн, 20.10»)
- Слоты времени 09:00–20:00 с шагом 1 час; занятые и прошедшие слоты
  блокируются автоматически
- Занятость слота считается по конкретной услуге: запись на стрижку
  не блокирует консультацию в то же время и наоборот
- На каждом шаге — кнопка «назад» к предыдущему шагу и кнопка главного меню;
  на шагах даты и времени показывается выбранная услуга
- Ввод имени и телефона с проверкой: имя 2–50 символов, телефон 10–11 цифр
- Экран подтверждения с полной сводкой записи и кнопкой «исправить телефон»
- Уведомление админу в Telegram (или в консоль, если `ADMIN_CHAT_ID` не задан)
- `/my_bookings` — активные записи клиента
- `/cancel` и кнопка «Отменить запись» — список всех активных записей
  кнопками: отменяется любая конкретная, а не только последняя
- `/today` — расписание на сегодня (только для администратора)
- Защита от двойного бронирования: слот проверяется при выборе времени
  и повторно перед сохранением, плюс уникальный индекс в базе
- Защита от устаревших кнопок: старые шаги диалога корректно отклоняются
- Хранение в SQLite: файл `bookings.db` создаётся рядом с ботом

## Стек

Python 3.10+ · aiogram 3.x · aiosqlite · python-dotenv · SQLite

## Установка и запуск

### Windows (PowerShell)

```powershell
# 1. Создать виртуальное окружение
python -m venv venv

# 2. Активировать его
venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать файл конфигурации из примера
copy .env.example .env

# 5. Открыть .env в блокноте и вписать токен (и, по желанию, ADMIN_CHAT_ID)
notepad .env

# 6. Запустить бота
python bot.py
```

### macOS / Linux (терминал)

```bash
# 1. Создать виртуальное окружение
python3 -m venv venv

# 2. Активировать его
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Создать файл конфигурации из примера
cp .env.example .env

# 5. Открыть .env в редакторе и вписать токен
nano .env

# 6. Запустить бота
python bot.py
```

Остановка бота: `Ctrl+C` в терминале.

## Как получить BOT_TOKEN

1. Откройте в Telegram бота **@BotFather**.
2. Отправьте команду `/newbot`.
3. Придумайте название бота (например, «ЗаписьПро Демо»).
4. Придумайте username — обязательно заканчивается на `bot`
   (например, `zapispro_demo_bot`).
5. @BotFather пришлёт токен вида `1234567890:AAH...` — вставьте его
   в файл `.env` после `BOT_TOKEN=`.
6. Аватар бота: там же у @BotFather команда `/setuserpic` — загрузите
   файл `bot_avatar.png` из папки `assets` репозитория.

## Как получить ADMIN_CHAT_ID

1. Откройте бота **@userinfobot**.
2. Нажмите «Start» — он пришлёт ваш числовой ID (например, `123456789`).
3. Вставьте его в `.env` после `ADMIN_CHAT_ID=`.
4. Если оставить поле пустым — уведомления админа будут печататься
   в консоль, где запущен бот (удобно для первого теста).

## Тестовый сценарий (7 минут)

1. Найдите своего бота в Telegram по username, нажмите «Start» (`/start`).
2. «📅 Записаться» → «Консультация специалиста — 1000 ₽» → завтрашняя дата →
   «🕐 10:00». Проверьте, что на шагах даты и времени показывается
   выбранная услуга и есть кнопки «назад».
3. Имя: `Анна`. Телефон: `+7 999 123-45-67`. Сверьте сводку → «✅ Подтвердить».
4. Пришло «Вы записаны! … №1»; админу — уведомление с тем же номером.
5. Снова «Записаться» → та же услуга и дата → слот 10:00 помечен «❌»,
   нажатие даёт «время занято для выбранной услуги».
6. Теперь выберите ДРУГУЮ услугу (например, «Стрижка») на ту же дату —
   слот 10:00 свободен: разные услуги идут параллельно. Запишитесь.
7. Телефон из 30 нулей или из 9 цифр не принимается: бот просит 10–11 цифр.
8. На шаге ввода телефона нажмите «⬅️ Исправить имя» — вернётесь к имени
   без потери услуги, даты и времени.
9. `/my_bookings` — обе записи в списке.
10. `/cancel` — бот показал список записей кнопками; нажмите первую —
    отменилась именно она, вторая осталась; админу пришло уведомление,
    слот освободился (проверьте выбором времени).
11. Если вы админ (`ADMIN_CHAT_ID` задан): `/today` покажет расписание
    на сегодня; с чужого аккаунта команда недоступна.

## Как показать демо клиенту

1. Запустите бота на своём компьютере (`python bot.py`).
2. Отправьте клиенту ссылку на бота: `t.me/<username_бота>` — клиент может
   сам пройти запись со своего телефона.
3. Попросите клиента записаться на любое время — вам (как админу) мгновенно
   придёт уведомление. Покажите его на созвоне с демонстрацией экрана.
4. Дополнительно запишите видео 60 секунд (OBS Studio, бесплатно):
   запись клиента → уведомление владельца → «соберу такой же под ваш бизнес
   за 3–5 дней».

## Что можно доработать под реального клиента

- Свой каталог услуг, цены, длительность услуг (сейчас слот = 1 час)
- Несколько мастеров/сотрудников с отдельными расписаниями
- Выходные, обеденные перерывы, индивидуальный график
- Выгрузка записей в Google Sheets или переход на PostgreSQL
- Напоминание клиенту за N часов до визита
- Онлайн-предоплата (эквайринг подключается через аккаунт клиента)
- Рассылка по базе клиентов
- Админ-панель: просмотр и отмена любых записей, статистика
- Вынос на круглосуточный бесплатный хостинг (PythonAnywhere free,
  Render free) — чтобы бот работал, когда ваш компьютер выключен
