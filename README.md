# Демо-проекты: Telegram-боты, автоматизации, парсинг

Портфель рабочих демо, которые можно потыкать руками до заказа.
Каждый проект запускается локально за 2–5 минут по своему README.

| Проект | Что показывает | Стек |
|---|---|---|
| [BotRecord](BotRecord/) | Telegram-бот онлайн-записи: услуги, календарь, слоты без двойных записей, уведомления владельцу, отмена записи | Python, aiogram 3.x, SQLite |
| [AutomationDemo](AutomationDemo/) | Сайт записи: форма → экран подтверждения с правкой значений → заявка с номером; занятые слоты считаются по конкретной услуге; кабинет клиента `/my` (свои записи и отмена по телефону); кабинет владельца `/admin` по ключу — таблица заявок и выгрузка CSV/XLSX, открывающаяся в русском Excel; уведомление в Telegram; адаптивная вёрстка | Python, aiohttp, SQLite, openpyxl |
| [ParserDemo](ParserDemo/) | Сбор каталога (цены, наличие, рейтинг) в CSV за минуты вместо ручного копипаста | Python, aiohttp, BeautifulSoup |

## Как смотреть

1. Выбрать проект, открыть его README.
2. Выполнить команды установки и запуска (всё бесплатно, локально).
3. Пройти тест-сценарий из README — он занимает 1–5 минут.

## Для клиентов

Каждое демо повторяется под конкретный бизнес за 1–7 дней: меняются услуги,
тексты, часы работы, источники данных. Стоимость и состав работ — по пакетам
в кворках профиля.
