# AutomationDemo — сайт записи: форма → база → уведомление в Telegram

Демо-проект для портфолио. Показывает малому бизнесу, как запись работает
через сайт: клиент выбирает услугу, дату и свободное время, заявка попадает
в базу, отображается владельцу таблицей и мгновенно уходит ему в Telegram.
Каталог услуг, даты и слоты — те же, что у бота BotRecord: демо показывает
единую логику записи для сайта и для Telegram.

## Для кого этот проект

- Салоны, клиники, барбершопы, фитнес, автосервисы — любой бизнес с записью
- Владельцы сайтов, у которых заявки сейчас приходят «в никуда»: почта,
  мессенджеры, блок «позвоните нам»
- Маркетологи и студии, которым нужен быстрый блок записи на лендинг клиента

## Какие проблемы решает

- Заявки не теряются: каждая попадает в базу и в уведомление владельцу
- Клиент видит только свободное время — нет звонков «а на 15:00 можно?»
- Двойная запись на одну услугу и время исключена технически
- Разные услуги могут идти в одно время (параллельные мастера/кабинеты)
- Владелец видит все заявки таблицей и выгружает их в Excel одним кликом
- Клиент сам отменяет запись по телефону — слот сразу освобождается

## Возможности

- Форма записи: имя, телефон, услуга, дата на 7 дней, слоты 09:00–20:00
- Занятые и прошедшие слоты блокируются в форме при выборе даты и услуги
- Занятость слота считается по конкретной услуге, как в боте
- Проверки ввода: имя от 2 символов, телефон 10–11 цифр; при ошибке
  введённые значения НЕ сбрасываются — форма возвращается заполненной
- Номер записи: показывается клиенту, приходит владельцу в Telegram,
  виден в таблице и выгрузках
- Страница `/leads` — таблица заявок владельца со статусами
  (активна / отменена) и выгрузками CSV и XLSX
- XLSX-выгрузка открывается в Excel без «кракозябр» и без превращения
  телефона в число вида 9E+10: телефон и дата хранятся текстом,
  ширина колонок настроена
- Страница `/cancel` — клиент вводит телефон, видит свои активные записи
  и отменяет нужную; владелец получает уведомление, слот освобождается
- Уведомления владельцу в Telegram (или в консоль, если `ADMIN_CHAT_ID`
  не задан); форма не зависает, если Telegram временно недоступен
- Клиент не видит служебных ссылок: страница подтверждения показывает
  только номер записи и ссылку на отмену

## Стек

Python 3.10+ · aiohttp · aiosqlite · python-dotenv · openpyxl · SQLite

## Установка и запуск

### Windows (PowerShell)

```powershell
# 1. Создать виртуальное окружение
python -m venv venv

# 2. Активировать его
venv\Scripts\activate

# 3. Установить зависимости
pip install aiohttp aiosqlite python-dotenv aiohttp-socks openpyxl

# 4. Создать файл конфигурации из примера
copy .env.example .env

# 5. Вписать токен бота и свой Telegram ID (можно оставить пустым —
#    тогда уведомления печатаются в консоль)
notepad .env

# 6. Запустить демо-сервер
python server.py
```

### macOS / Linux (терминал)

```bash
python3 -m venv venv
source venv/bin/activate
pip install aiohttp aiosqlite python-dotenv aiohttp-socks openpyxl
cp .env.example .env
nano .env
python server.py
```

Остановка: `Ctrl+C` в терминале.

## Как получить BOT_TOKEN и ADMIN_CHAT_ID

1. **@BotFather** → `/newbot` → токен вида `1234567890:AAH...` → в `.env`.
2. **@userinfobot** → Start → ваш числовой ID → в `.env` после `ADMIN_CHAT_ID=`.
3. Если провайдер блокирует Telegram (частая история в РФ) — впишите
   рабочий HTTP-прокси в `PROXY_URL=http://адрес:порт`.

## Тестовый сценарий (5 минут)

1. Откройте http://127.0.0.1:8080, введите имя и телефон, выберите
   «Консультация специалиста», завтрашнюю дату и время 10:00 → отправить.
2. Страница подтверждения показывает номер записи; владельцу пришло
   уведомление в Telegram с тем же номером, датой и временем.
3. Откройте форму снова: та же услуга и дата — слот 10:00 в списке
   недоступен; выберите «Стрижку» — 10:00 снова свободен (разные услуги
   идут параллельно). Запишитесь.
4. Отправьте заявку с телефоном из 30 нулей — форма вернётся с ошибкой
   и СОХРАНЯЕТ введённые имя, услугу и дату: заполнять заново не нужно.
5. Откройте http://127.0.0.1:8080/leads — обе записи в таблице.
   Скачайте XLSX и откройте в Excel: телефон и дата на своих местах,
   колонки не «######».
6. Откройте http://127.0.0.1:8080/cancel, введите телефон — увидите список
   своих записей; отмените одну — слот освободился (проверьте в форме),
   владелец получил уведомление об отмене, в таблице статус «отменена».

## Как показать демо клиенту

1. Запустите `python server.py` и откройте форму на демонстрации экрана.
2. Пройдите запись за 20 секунд: услуга → дата → время → отправить.
3. Покажите прилетевшее уведомление в Telegram и таблицу /leads.
4. Продемонстрируйте защиту: та же услуга и время недоступны, другая
   услуга — доступна; отмена записи освобождает слот.
5. Запишите видео 60 секунд (OBS Studio, бесплатно) — этот сценарий и есть
   готовый скрипт ролика.

## Что дорабатывается под реального клиента

- Вставка формы на реальный сайт клиента (Tilda, WordPress, любой HTML)
- Отправка заявок в Google Sheets или CRM клиента вместо локальной базы
- Несколько специалистов с отдельными расписаниями и выходными
- Уведомления разным менеджерам, рабочие часы, автоответы клиенту
- Напоминания клиенту за N часов до визита
- Вынос на хостинг, чтобы форма работала круглосуточно
