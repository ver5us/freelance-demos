# AutomationDemo — форма → база → уведомление в Telegram

Демо автоматизации для портфолио. Показывает малому бизнесу, как заявка с сайта
перестаёт теряться: попадает в базу, отображается на странице-таблице и мгновенно
уходит владельцу в Telegram.

## Что умеет

- Форма заявки (имя, телефон, услуга, комментарий) с проверкой ввода
- Сохранение заявки в SQLite (`leads.db`)
- Мгновенное уведомление владельцу в Telegram (или в консоль, если `ADMIN_CHAT_ID` не задан)
- Страница `/leads` — все заявки таблицей (аналог Google Sheets для демо)
- Выгрузка `/export.csv` — заявки одним файлом для Excel

## Запуск

```powershell
python -m venv venv
venv\Scripts\activate
pip install aiohttp aiosqlite python-dotenv aiohttp-socks
copy .env.example .env
notepad .env        # вписать BOT_TOKEN, ADMIN_CHAT_ID, при необходимости PROXY_URL
python server.py
```

macOS / Linux: `source venv/bin/activate`, `cp .env.example .env`, `python server.py`.

## Как проверить за 2 минуты

1. Открыть http://127.0.0.1:8080 и отправить заявку.
2. Увидеть страницу «Заявка принята»; владельцу придёт уведомление в Telegram.
3. Открыть http://127.0.0.1:8080/leads — заявка в таблице.
4. Скачать http://127.0.0.1:8080/export.csv и открыть в Excel.
5. Отправить заявку с телефоном из 3 цифр — форма не примет и покажет ошибку.

## Как показывать клиенту

Записать видео 60 секунд: заполнение формы → уведомление в Telegram → страница
заявок → CSV в Excel. Формулировка для переписки: «Вот как выглядит связка
"форма → таблица → уведомление": заявка не теряется, вы видите её за 5 секунд».

## Что дорабатывается под реального клиента

- Отправка заявок в Google Sheets или CRM клиента вместо локальной базы
- Несколько форм и страниц на реальном сайте клиента
- Уведомления разным менеджерам, рабочие часы, автоответы клиенту
- Вынос на хостинг, чтобы форма работала круглосуточно
