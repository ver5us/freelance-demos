# AutomationDemo — форма записи → база → уведомление в Telegram

Демо автоматизации для портфолио. Показывает малому бизнесу, как заявка с сайта
перестаёт теряться: клиент сам выбирает дату и свободное время, заявка попадает
в базу, отображается на странице-таблице и мгновенно уходит владельцу в Telegram.

## Что умеет

- Форма записи: имя, телефон, услуга, комментарий — с проверкой ввода
- Выбор даты на 7 дней вперёд и слотов времени 09:00–20:00, как в боте записи
- Занятые и прошедшие слоты блокируются в форме автоматически
- Двойная запись на одни дату и время исключена: проверка на сервере
  плюс ограничение UNIQUE в базе (даже при одновременных заявках)
- Каждая заявка получает номер: он показывается клиенту, владельцу
  в уведомлении и в таблице
- Страница `/leads` — все заявки таблицей (аналог Google Sheets для демо)
- Выгрузка `/export.csv` — заявки файлом для Excel (разделитель «;», UTF-8 BOM)

## Запуск

```powershell
python -m venv venv
venv\Scripts\activate
pip install aiohttp aiosqlite python-dotenv aiohttp-socks
copy .env.example .env
notepad .env        # вписать BOT_TOKEN, ADMIN_CHAT_ID, при необходимости PROXY_URL
python server.py
```

macOS / Linux: `source venv/bin/activate`, `cp .env.example .env`, `python server.py`.

## Как проверить за 3 минуты

1. Открыть http://127.0.0.1:8080, выбрать дату и время, отправить заявку.
2. На странице подтверждения увидеть номер записи; владельцу мгновенно придёт
   уведомление в Telegram с тем же номером, датой и временем.
3. Открыть http://127.0.0.1:8080/leads — заявка в таблице с датой и временем.
4. Отправить вторую заявку на те же дату и время — форма не примет её
   и покажет «время только что заняли, выберите другой слот».
5. В форме на этой же дате слот уже помечен недоступным в списке времени.
6. Отправить заявку с телефоном из 3 цифр — форма не примет и покажет ошибку.
7. Скачать http://127.0.0.1:8080/export.csv и открыть в Excel — данные по колонкам.

## Как показывать клиенту

Записать видео 60 секунд: заполнение формы с выбором слота → страница с номером
записи → уведомление в Telegram → таблица заявок → попытка занять то же время
и отказ. Формулировка для переписки: «Вот как выглядит связка "форма → таблица →
уведомление": заявка не теряется, вы видите её за 5 секунд, а двойные записи
исключены технически».

## Что дорабатывается под реального клиента

- Отправка заявок в Google Sheets или CRM клиента вместо локальной базы
- Несколько форм, услуг и специалистов с отдельными расписаниями
- Уведомления разным менеджерам, рабочие часы и выходные, автоответы клиенту
- Вынос на хостинг, чтобы форма работала круглосуточно
